# 🎨 AI Background Remover

100% free, open-source background removal tool. Runs forever on Hugging Face Spaces.

## ✨ Features
- 🚀 One-click background removal
- 🎯 High quality (uses `briaai/RMBG-1.4` model)
- 🔒 Privacy-first: images processed in real-time, never stored
- 💰 Free tier + Pro upgrade path
- 📱 Mobile-friendly interface

## 🚀 Live Demo
👉 https://huggingface.co/spaces/AlexanderGreater90/ai-bg-remover

## 🛠️ Tech Stack
- **Frontend:** Gradio (Python)
- **Model:** `briaai/RMBG-1.4` (Apache 2.0 license)
- **Hosting:** Hugging Face Spaces (free CPU tier)
- **Library:** `rembg` for inference

## 📦 Local Development
```bash
pip install -r requirements.txt
python app.py
```

## 💼 Monetization
- Free tier: 5 images/day (with watermark optional)
- Pro tier: $9/mo (Stripe/Lemon Squeezy integration)
- API access: $0.10/image
